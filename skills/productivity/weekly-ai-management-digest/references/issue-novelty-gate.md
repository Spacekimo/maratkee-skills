# Issue Novelty Gate

Run this gate before outlining every recurring digest issue. It preserves continuity without re-running last week's argument.

## 1. Map the preceding issue

Record, in one sentence each:

- its central thesis;
- the management object it addressed (for example: adoption, an AI-assisted change, a delivery system, a team operating model, or portfolio impact);
- its key evidence and action items.

## 2. State the current issue's novelty

Before completing the outline, define:

> This issue helps a manager make or improve **[specific decision]** about **[specific object]** using **[new evidence or mechanism]**.

The object, decision, or mechanism must materially differ from the preceding issue. A fresh source alone does not create novelty.

## 3. Classify planned material

Mark every planned section and action item:

- **new core** — introduces the current issue's distinct decision, object, mechanism, or evidence;
- **bridge** — connects to the previous issue in one or two sentences;
- **repeat** — restates a prior conclusion without adding a new decision, mechanism, or evidence.

Remove `repeat` material. Keep bridges short. At least three quarters of visible prose and every action item should be `new core`.

## 4. Test the title and opening

The title, description, opening, and first section should name the new management object directly. Do not start by re-proving the preceding issue's headline. A contextual link to it is useful only when it makes the progression explicit.

## 5. Record the decision

In the editorial review, record:

- preceding issue thesis;
- current issue thesis;
- retained bridge material;
- repeated material removed;
- the reader's new decision or object.
